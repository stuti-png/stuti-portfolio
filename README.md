# Stuti’s portfolio

A personal portfolio built with React, TypeScript and Vite.

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Production files are generated in `dist/`. Portfolio content lives in `src/content/`, with images, fonts and the introduction video in `public/`.

## Website

https://stuti-png.github.io/stuti-portfolio/

GitHub Pages serves the production build from the `gh-pages` branch. The source is maintained on `main`; rebuild and update `gh-pages` when publishing changes. Only the production files in `dist/` are published.
